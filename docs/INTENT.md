# 意图台账：原意、实现映射与缺口

> Working record kept in Chinese, the language the decisions were made in. For an English overview, see [README.md](../README.md).

这份台账是 Dream Street 的"意图单一来源"。任何接手的人或 AI 助手都先读它；Jovi 可以先改"解释"一栏，再让我们动手。每一行都写成可观察的判据，避免再出现"反复修改却修错了自由度"的情况。

- **来源**：H0–H2 来自首轮方案交接（H0001）中的梦境记录；R1–R8 是 Jovi 在实现过程中的反馈（2026-09-08 至 09-30 的开发会话）。
- **状态**：`已实现` 表示有测试或实测证据；`待评审` 表示只有 Jovi 看过、听过才能判断；`后续` 表示已知缺口、排在以后的迭代。
- 原话只摘短句；完整记录保存在维护者的私有工作记录中，不随仓库公开。

## 三、2026-09-28 交叉审核结论

**为什么"僵尸手"改了三轮还在。** 每一轮都在重写"手放在哪儿"，问题却出在"肘朝哪边"。手臂 IK 与膝盖共用一个朝前的方向参数（`pose.js` 原第 21 行、`rig.js` 原第 270 行），手一交给 IK，肘部就被推到身前、上臂前抬。

G2.2 在花间段发现"双臂架着"，但只在局部改了方向。验证只靠两类证据：一是约 90 像素高的截图，二是只量弯曲幅度、不量朝向的测试，所以一直没发现。探针测得，修复前路人模仿时有 95% 的采样肘部在身前，修复后为 0.9%，且剩下的都是手在肩部以上的正常姿势。

**音乐两次都偏了。**
- 最初的合成配乐缺少侧链、饱和、混响总线，所以没有力量。
- 改用原曲后，画面仍按 120 BPM 走，原曲却约为 130 BPM，于是"步伐合拍"这条根本约束被丢掉了。
- 放宽"四连精确踩原曲重音"，不等于可以放弃合拍。

**四连被稀释了。** G1 的专属四连舞句在 G2.1 被通用舞句替换；G2.2 又把显现拉长，衣服要到重音之后才换好；手里还一直握着手杖。

**工程问题。**
- `sample()` 有副作用。
- 旧编曲不发声，但它的调度器仍暗中承担 YouTube 音量和本地音频增益两件事。
- 常量散落在各处，源码是压缩式写法。

以上均已在 `feature/music-and-motion` 分支处理，逐项见提交记录。

**方法上的改进。**
- 每一轮都在同一拍号截取特写前后对照（`scripts/review-frames.mjs`）。
- 离线渲染各章节音频并附上客观指标（`scripts/render-music.mjs`）。
- 身体问题先量化，再修改，最后固化成测试。

## 四、2026-09-30 G2.4 结论

**弹跳感从哪里来。** 旧编曲让每一记底鼓都把贝斯、和声压低约 7 dB（侧链闪避），再加上八度跳贝斯和锯齿波拨弦，整首曲子随底鼓一起一伏。摇滚乐队是一起发声的，所以新混音器里不再有闪避。"搞怪电子感"来自钟琴、clav、supersaw 和电子上升音效，这些都已删除。

**路人为什么像被变出来。** 旧路线从主角身后二十多个单位处出发，一路追上来，所以人群看起来是冲着主角来的。现在每个人都锚定在街上的某个位置：

- 站着的人都站在同一条线上：远侧站在橱窗线，近侧站在墙边线；
- 迎面走来的人走到最后一个站着的人之后才掉头；
- 靠内的列先入队。

这样无论谁先动身，都不会从别人身上穿过去。数值检查器验证了间距、速度、是否穿墙和是否挡住倒影，再把这些要求固化成测试。

**混音靠测量配平。** 我听不到声音，所以逐轨单独渲染、测响度：

- 第一版贝斯单轨就有 −8.7 dB RMS，比鼓高 7 dB，母线压缩器几乎只在压它；
- 母线压缩把律动段和四连压成同一响度后，改为让四连之前的律动稍弱、铺垫渐强到重击，并按响度统一每个吉他和弦。

最终四记重击高于白天章 98%–100% 的时刻。

**再往干净里收（同日，G2.5）。** Jovi 听后指出配乐"电子金属音"太多、太杂，想要老派摇滚的干净。最像"电子金属"的是镲片：它原本用六个方波叠加，正是 1980 年代鼓机的做法，天生带电子味。现在改为以噪声为主、逐渐变暗的镲片。其余改动见 R8。删掉合唱和各种效果后，鼓一度被盖住；按分轨测量重新推回乐队最前面。

## 五、已知缺口（后续迭代）

- 每套衣装各自的舞蹈语汇仍然很弱（R2-8 的后半部分）。
- 四连期间，画面右上方远处能看到几位在路口等候、在唱片店橱窗前浏览的路人，他们静止不动。原方案要求四连不被抢焦点，这是否仍然抢焦点，待评审。
- 四连橱窗里，倒影与四个人台叠在一起，难以辨认。
- 配乐仍是纯合成音色，吉他来自物理模型。若听起来仍不像真实乐队，下一步可以考虑经过许可核验的 CC0 采样，或授权音乐。
