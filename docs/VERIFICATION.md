### 变更与证据

- **直接使用指定原曲**：默认 YouTube 视频 ID 为 `knOXppaqBYY`，标题 `Ecstatic Vibrations, Totally Transcendent`，作者 `Sea Power - Topic`。旧的默认原创模式、花店间奏回切和分段音量渐变已从正常体验移除。原曲越过第 148、208、256 拍持续播放；整首歌曲结束才循环，行程继续。
- **自然摆臂**：行走使用肩、肘、腕的关节弧线和错开的相位；手部目标不再将肘部拉到锁直。保留支撑脚以及挥手时手势控制，路人正常接近时使用同一实现。
- **换装折光**：新旧衣料有沿高度移动的显现分界，金绿光沿布面游走，两个预建光带上行并消退。普通换装 1.8 拍、四连 1.15 拍、旧装回归 2.2 拍，放宽旧编曲的精准重音要求。光带和人物在同一倒影通道中，受玻璃边界和遮挡裁切。
- **花间身体语言**：采用 32 拍长句，包含低肘位、收拢、视线落向花束、停留、缓慢打开与收回；脚保持着地。服装的快速胸肩与手腕修饰不再叠入该段。物品变化不会重启全身舞句。
- **骑车回应**：两位骑车人在参与前、离开时都有抬手、点头和看向主角的动作；一只手保留在握把上。用户认可的四组双向告别，其事件与路线保留。

音乐是一首持续的原曲。视觉章节的花间、同行、游乐不再被描述为原曲中已识别的换曲或情绪段落；本轮没有进行原曲节拍检测，也没有承诺四次换装精确踩中歌曲重音。

## 实时录制与运行采样

录制和采样由 `npm run capture` 生成，完整机器记录位于 `artifacts/g1/capture-report.json`。使用 1440 × 900、DPR 1，实际渲染主场景和倒影两遍，绘制调用统计在两遍之前统一清零。帧间隔以 `performance.now()` 测量，包含浏览器调度、录制和两次渲染之间的间隔；不是单独 GPU 耗时，也不代表高 DPR 或其他设备的表现。

脚本连续运行约 125 秒，覆盖三个完整 80 拍街道循环后进入第四轮；每 20 秒采样对象、纹理、声音和调度器。视频的前 40.5 秒为原镜头、正常速度、应用 Canvas 加应用音频流；不是离线逐帧动画，也没有外部配音。录制音频支路根据输出时间映射补偿延迟，但未使用外部回环设备测量扬声器和显示器之间的绝对同步误差。

最终数值在 `capture-report.json` 中以 `final.visual`、`final.audio` 和 `samples` 为准。首次经过全部街段会有 GPU 几何预热增长，后续同相位采样应保持稳定；没有用强制归零时间或每轮重建场景来通过稳定性检查。
