### 手臂：从"僵尸手"到解剖方向

用探针对主角、倒影、5 名路人和骑车人扫一整轮，统计肘部落在"肩—手连线"前方超过 0.02 的采样占比：

| 角色 | 修改前 | 修改后 |
| --- | --- | --- |
| 倒影舞蹈 | 67.2% | 0.7% |
| 路人模仿 | 95.4%（上臂抬起中位 49°） | 0.9%（31°） |
| 骑车人空手 | 49.0% | 0% |
| 主角步行 | 1.6%（上臂 10°，肘部变化约 9°） | 0%（上臂 16°，肘部 15°–45°） |

修改后剩下的"朝前"采样，手都在肩部高度或更高，属于握拳收在胸前这类自然的折叠手臂。新增的 `tests/unit/anatomy.test.js` 要求：手低于肩时肘部不得超出肩—手连线往前，纯走路时手在腰胯以下、上臂抬起不超过 30°。同拍号的特写对照由 `scripts/review-frames.mjs` 生成（`artifacts/review/before-arms`、`after-arms`、`after-fourhit`），不纳入 Git。

### 四连

第 50、52、54、56 拍依次是：短夹克压帽、宽肩外套胸肩顿挫、长外套转身、开袖套装打开身体。测试逐拍确认三件事：衣服已完成显现（进度大于 0.99）、手上没有道具、标志姿势到位。第 45.6 拍得到的手杖在第 48 拍放下，第 48.8 拍完全消失。舞句在第 48 拍和第 60 拍进出，衔接连续性测试照常通过。

### 原创配乐

离线渲染经过与实时播放相同的混音链，结果见 `artifacts/music/v1c/metrics.json`。其中 RMS 为未加权电平，满幅正弦波约为 −3 dBFS。

| 片段 | 峰值 | RMS |
| --- | --- | --- |
| 电光 0–80 | −0.49 dBFS | −11.97 dBFS |
| 同行 80–144 | −0.49 | −13.00 |
| 花间 144–208 | −0.57 | −15.36 |
| 游乐 208–256 | −0.49 | −14.13 |

- **四连重击：** 起音在拍点后 1.2–1.9 ms，即瞬态自身的起音时间；每记重击后 300 ms 的响度，超过全章 96%–100% 的 300 ms 窗口。
- **修正前（`v1`）：** 峰值高达 +0.56 dBFS；花间段 RMS −6.2 dB，反而最响，低频占比 77%；起音晚 18 ms。
- **晚 18 ms 的原因：** 用脉冲离线实测得到，单个 `DynamicsCompressor` 约有 6 ms 前视延迟，4 倍过采样的 `WaveShaper` 约 2.7–4 ms，整条混音链合计 14.7–16.9 ms。现在只保留一级压缩器，改用软削波；启动时实测剩余的 6 ms，并让音符提前发出。
- **单元测试还确认：** 每一拍都有可听的节拍；花间段没有重鼓；各入口前的铺垫恰好在入口处结束；乐谱查询是确定的，也可以任意分段。

## G2.2 · 身体语言与折光 · 2026-09-09

当前交付为 **0.4.0 / G2.2**。G0、G1 已实现；G2 主要功能已接入，目前进入体验专项收敛。G3 单键表达未实现且为可选，不是 G2 必须完成的前置。本轮不宣称已经完成所有四个节点或通过最终艺术体验验收。

### 变更与证据

- **直接使用指定原曲**：默认 YouTube 视频 ID 为 `knOXppaqBYY`，标题 `Ecstatic Vibrations, Totally Transcendent`，作者 `Sea Power - Topic`。旧的默认原创模式、花店间奏回切和分段音量渐变已从正常体验移除。原曲越过第 148、208、256 拍持续播放；整首歌曲结束才循环，行程继续。
- **自然摆臂**：行走使用肩、肘、腕的关节弧线和错开的相位；手部目标不再将肘部拉到锁直。保留支撑脚以及挥手时手势控制，路人正常接近时使用同一实现。
- **换装折光**：新旧衣料有沿高度移动的显现分界，金绿光沿布面游走，两个预建光带上行并消退。普通换装 1.8 拍、四连 1.15 拍、旧装回归 2.2 拍，放宽旧编曲的精准重音要求。光带和人物在同一倒影通道中，受玻璃边界和遮挡裁切。
- **花间身体语言**：采用 32 拍长句，包含低肘位、收拢、视线落向花束、停留、缓慢打开与收回；脚保持着地。服装的快速胸肩与手腕修饰不再叠入该段。物品变化不会重启全身舞句。
- **骑车回应**：两位骑车人在参与前、离开时都有抬手、点头和看向主角的动作；一只手保留在握把上。用户认可的四组双向告别，其事件与路线保留。

音乐是一首持续的原曲。视觉章节的花间、同行、游乐不再被描述为原曲中已识别的换曲或情绪段落；本轮没有进行原曲节拍检测，也没有承诺四次换装精确踩中歌曲重音。

## 视频和构建

视频提供 WebM 原始录制，以及 H.264 / AAC 的 MP4 便于播放。关键帧在 `frame-50.png`、`frame-52.png`、`frame-54.png`、`frame-56.png`；另有旧装、接触、间断、回归及 1600 × 900 构图图像。

音频存在性和峰值由 FFmpeg 测量；它只能证明录到了声音和电平范围，不能证明编曲已经好听。全速观看与实际试听仍由体验评审决定。

最终 MP4 长 40.500 秒，1440 × 900、60 fps，H.264 视频加 48 kHz 双声道 AAC，10,638,641 bytes。原始录音平均电平 −20.3 dBFS、峰值 −4.8 dBFS；媒体和电平记录在 `media-info.json`、`audio-analysis.txt`。MP4 转码保留原始实时录制的声音和画面节奏。

`npm run build` 通过。Vite 提示主 JavaScript chunk 超过 500 kB，主要含 Three.js；保留这条提示，没有提高警告阈值掩盖它。构建日志在 `artifacts/g1/build-results.txt`。网络访问只需安装依赖，应用运行本身没有远程素材请求、遥测或外部 API。

## G1 评审仍需决定

- 玻璃染色、透底与表面反光是否足以让倒影被认作“映出的形象”，同时仍看得清姿势。
- 真人与倒影是否自然被认作同一个人，四套服装轮廓和脚下重量是否成立。
- 能否在完整镜头里看到商品先出现、接触后换装，连续四次变化与音乐重音是否清楚。
- 原创七声部音乐是否形成愿意继续听的乐句；旧装恢复以后，舞蹈的力量是否还在。

这些问题未通过之前继续修改核心片段，不扩展 G2。包含人群的 10 分钟稳定性测试属于 G2，本轮未执行。
