# Dream Street · 街道与倒影

一个一直向前走的人，和玻璃里一直跳舞的他。白昼、宽街、旧衣服与新舞步；不操作也能完整观看。

当前交付是 **G0 + G1**：约 40 秒的原创角色、服装、连续编舞和七声部音乐，随后有限街道与乐段继续衔接。未进入 G2 人群、道具和六类店面，也未加入 G3 节奏输入。

## 运行

本轮使用 Node 24.20.0、npm 11.19.0。依赖固定为 Three.js 0.185.1、Vite 8.2.2、Playwright Test 1.63.0，使用项目内 `package-lock.json`。

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/`，点击「开始前行」启音。页面隐藏会暂停；返回后点击「继续」。静音不会暂停行程。开发和预览服务均只监听 `127.0.0.1`。

```sh
npm test
npm run test:browser
npm run build
npm run preview
```

浏览器测试使用本机安装的 Google Chrome；不会自动安装或替换浏览器。正式构建在 `dist/`，预览通常使用 `http://127.0.0.1:4173/`。需要 WebGL 2 和 Web Audio。小屏有构图适配，但本轮验收尺寸为 1440 × 900、1600 × 900。

## 观看与评审

| 时间 | 片段 |
| --- | --- |
| 0–8 秒 | 真人旧衣行走，倒影旧衣舞蹈 |
| 8–24 秒 | 商品投影交叠换装，短暂实墙遮断 |
| 24–30 秒 | 四连：压帽、胸肩顿挫、转身站稳、打开身体 |
| 30–32 秒 | 办公楼玻璃内保留新装 |
| 32–40 秒 | 收势恢复旧装，舞步继续 |

四连接触拍为 `49.65 / 51.65 / 53.65 / 55.65`，重音拍为 `50 / 52 / 54 / 56`。120 BPM 下接触比重音早 175 ms。办公楼入口为第 60 拍，旧装回归为第 64 拍。

依照实现期间的反馈，倒影带有玻璃染色、透底和跨越身体的表面反光，并减弱明暗体积感；它需要被读作附着在玻璃上的映像。换装与舞步继续独立求值。

重点评审：是否认得出同一个人、商品与换装的因果是否清楚、四个动作及衣装轮廓是否可辨、倒影是否像映像、旧装回来以后是否仍想继续观看。技术检查不能替代这些判断。

## 调试与演示文件

打开 `http://127.0.0.1:5173/?debug=1` 可从头重看、跳到四连或回归段、显示接触线、录制带程序内音频的 40 秒视频。普通界面不显示技术面板。

```sh
npm run capture
```

此命令用本机 Chrome 生成关键帧和实时 WebM 视频，连续运行约 125 秒，并写入 `artifacts/g1/capture-report.json`。如果本地 5173 没有服务，会启动并在结束时关闭自己创建的服务。已有开发服务保留。可用 `DREAM_STREET_SOAK_SECONDS` 延长采样。录制使用应用自身的 Canvas 与音频流，不是外部配音。

MP4 是交付时用本机 FFmpeg 转码的播放副本。重新录制会更新 WebM；需要更新 MP4 时执行：

```sh
ffmpeg -y -i artifacts/g1/dream-street-g1.webm -c:v libx264 -crf 19 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart artifacts/g1/dream-street-g1.mp4
```

交付文件位于 `artifacts/g1/`（不纳入 Git）：`dream-street-g1.mp4` / `.webm`、`frame-50.png`、`frame-52.png`、`frame-54.png`、`frame-56.png`、`frame-66.png`，以及 G0 裁切图和机器可读报告。

## 工程结构

- `src/content/plan.js`：街段、商品、接触、换装恢复的唯一内容计划。
- `src/audio/`：七声部乐谱、原创合成音色、输出时间映射、统一 Transport。
- `src/character/`：原创参数化骨架、五套几何衣装、步态与连续舞蹈曲线。
- `src/world/`：四个可复用街道模块、商店人台、玻璃与实墙。
- `src/render/`：固定正交镜头、单张倒影离屏纹理、玻璃投影合成和诊断。
- `tests/`：时间/状态单元测试及实际 Chrome 像素与交互测试。

真人与倒影共享一个 `travelS`，姿势在各自子层运行。离屏纹理由所有玻璃共享，以屏幕坐标采样，深度测试保留窗框和实墙遮挡。音频的前瞻调度不会提前修改画面。场景状态可按拍数直接恢复；衣装改变不重建角色，不重置舞步。

源码、素材来源与范围见 [ASSETS.md](docs/ASSETS.md)；实测结果和未完成验证项见 [VERIFICATION.md](docs/VERIFICATION.md)。Git 分支为 `codex/initial-prototype`，本轮不包含 commit、push 或发布。
