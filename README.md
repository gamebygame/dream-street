# Dream Street · 街道与倒影

一个一直向前走的人，和玻璃里表达自己的他。有人靠近，试着跟上几个舞步。到了路口，回头道一声再会。

当前版本 **0.4.0 / G2.2：身体语言与折光**。这轮将背景直接换为 Sea Power 的原曲，重做行走摆臂、换装显现、花间身体语言及骑车人的致意。保留用户认可的四组相互告别演出。128 秒街段之后持续接续。

## 阶段位置

原始 H0001 方案共有 **G0、G1、G2、G3 四个节点**，其中 G3 为可选项：

| 节点 | 当前状态 |
| --- | --- |
| G0 空间与双身 | 已实现；固定镜头、共享行程、单一倒影与玻璃裁切 |
| G1 核心记忆片段 | 已实现并获方向认可；四次接触、不同衣装及连续表演。按后续意见放宽与原曲重音精确同步的要求 |
| G2 完整持续街道 | 主要功能已接入：九类店面、八种编排道具、36 人、路口与告别、接续。当前在做体验专项收敛，G2.1、G2.2 是迭代编号，不是新增里程碑 |
| G3 可选单键表达 | 未实现、后置；原方案明确不作为 G2 成功的必要条件 |

可以继续专项优化，无需为了凑齐节点而添加输入玩法。画面、动作与音乐的体验验收仍由实际观看决定，测试通过不等于已经完整重现梦境。

## 运行

使用 Node 24.20.0、npm 11.19.0。Three.js 0.185.1、Vite 8.2.2、Playwright Test 1.63.0 固定在项目 lockfile 中。

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/`，点击「开始前行」播放原曲与街道。页面隐藏会暂停，返回后点击「继续」。静音只改变音量。开发和预览服务均只监听 `127.0.0.1`。

```sh
npm test
npm run test:browser
npm run build
npm run preview
```

浏览器测试使用已安装的 Google Chrome。构建在 `dist/`，默认预览端口 4173；本轮固定预览使用 4174。需要 WebGL 2 和 Web Audio，主要构图尺寸为 1440 × 900、1600 × 900。

## 全程原曲

默认播放用户指定的 [Ecstatic Vibrations, Totally Transcendent — Sea Power](https://www.youtube.com/watch?v=knOXppaqBYY)。采用可见的官方 YouTube 播放器；**花店、游乐段与街段接续均不切回、不混入旧原创音乐**。约 3 分 36 秒的整曲结束后循环，人物行程和衣装状态继续。

原曲不在 128 秒的街段边界重启。YouTube 播放时间驱动画面，缓冲时画面等待，播放器内拖动、暂停和恢复同步到场景。时钟是播放器时间估算；场景保留每秒 2 个内部拍号的时间单位，未宣称检测或精确对齐了原曲 BPM 与重音。

官方音源需要网络。如果无法连接，显示错误并等待重试，不自动回退旧编曲。也可在右上角「音乐」选择自己的本机音频，替代**全部**背景；文件只解码到当前浏览器内存，不上传、不存入仓库，重载后需重选。

旧合成编曲源码保留供历史与独立测试使用，正常应用不排程这些声部。`?music=silent` 仅用于离线动作检查，不能作为音乐交付。

## 这轮身体与换装

行走的肩、肘、腕沿各自略有滞后的弧线运动，肘部保持轻微弯曲。摆臂不再由容易锁直的手部目标牵引。脚下支撑约束保留；挥手、舞蹈和骑车握把继续使用手部目标控制。路人从同一正常步态逐渐进入模仿。

换装采用衣料上的金绿折光和两条上行光带，从下摆经过胸肩、最后收拢。显现时可见新旧衣料分界，特效和人物一起被玻璃、窗框与墙体裁切。普通显现约 0.9 秒，四连每次约 0.575 秒，旧装回归约 1.1 秒，另有短暂光带收尾。特效复用预建几何，不创建第二个角色，不重置表演相位。四次接触时间保持原位，显现不再被压缩到 175 毫秒来追赶旧编曲重音。

| 时间 | 身体语言与场景 |
| --- | --- |
| 0–40 秒 | 移重心、脚尖脚跟、抬帽与短暂定势；服装、唱片、钟表、古董和办公楼 |
| 40–72 秒 | 降低重心的同行律动；路人先正常行走，再逐渐参与 |
| 72–104 秒 | 32 拍长句：收拢、呼吸、停留、缓慢打开与收回；脚保持着地，去掉快节奏胸肩与手腕修饰。花束收在胸前、端详、呈递；玫瑰与视线引导转身；持伞时自由手有克制的回应 |
| 104–128 秒 | 恢复好奇、轻快的身体语言；木偶、咖啡与礼品 |

这些是**表演章节**，不宣称原曲在相同时间点切换曲风或进入抒情间奏。花间表达在持续的原曲下采用更长、更克制的动作句，音乐与情绪的最终适配仍需观看评审。

两位骑车人在开始模仿前和离开时都安排抬手、点头、看向主角；靠近时有持续的视线回应。另一只手保持握把，脚与车轮依行程运动。四组路人与主角互相致意的事件、路径和时序保持原样。

## 录制与验证

`http://127.0.0.1:4174/?debug=1` 提供跳转、接触线和录制。官方在线播放不能进入应用的录音图，因此该模式明确导出 **无声画面**；含音轨导出须选择自己的本机音频。

```sh
npm run capture
```

默认让官方原曲在页面实际播放，录制 128.5 秒原速、原镜头的**无声** WebM，同时连续运行 600 秒。报告与关键帧写入 `artifacts/g2-2/`。可用 `DREAM_STREET_URL` 指定预览服务，`DREAM_STREET_SOAK_SECONDS` 改变时长；`DREAM_STREET_MUSIC=silent` 是显式离线检查选项，报告会记录所用来源。

```sh
node scripts/verify-reference.mjs
ffmpeg -i artifacts/g2-2/dream-street-g2-2-silent.webm -c:v libx264 -crf 19 -pix_fmt yuv420p -an -movflags +faststart artifacts/g2-2/dream-street-g2-2-silent.mp4
```

`verify-reference.mjs` 单独联网检查默认原曲、花店段连续播放、128 秒边界、暂停恢复、静音、播放器内拖动与整曲循环。常规浏览器回归使用显式无声模式和临时 WAV 测试音，不依赖 YouTube 网络。

媒体与报告不纳入 Git；G1、G2、G2.1 历史媒体保留原位。旧视频里的原创音乐不代表当前版本。

## 代码与来源

- `src/content/`：256 拍街段、商品状态、表演章节、路人和骑车人的路径及致意事件。
- `src/character/`：参数化母本、独立骨架、步态、衣料折光与连续姿势曲线。
- `src/audio/`：统一时间、官方播放器和本机音频；历史合成编曲不进入正常应用播放。
- `src/world/`：三个复用街道池、36 人实例绘制、两个预建自行车角色。
- `src/render/`：固定正交镜头、共享倒影纹理、玻璃透底染色、反光与深度裁切。
